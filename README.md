
# Sales and Financial Performance Analysis

## Project Overview

This project focuses on analyzing business sales
and financial performance using Python, SQL,
Excel and Power BI.

The main objective is to identify sales trends,
product performance, profitability and the
impact of discounts on business performance.

## Dataset Description

The dataset contains the following fields:

- Segment
- Country
- Product
- Discount Band
- Units Sold
- Manufacturing Price
- Sale Price
- Gross Sales
- Discounts
- Sales
- COGS
- Profit
- Date
- Month Number
- Month Name
- Year

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- MySQL Workbench
- Microsoft Excel
- Power BI

## Project Workflow

1. Data loading and inspection
2. Data cleaning using Python
3. Handling missing values and duplicates
4. Exploratory Data Analysis
5. SQL-based business analysis
6. Excel pivot tables and charts
7. Interactive Power BI dashboard
8. Business insights and recommendations

## Key Analysis

- Country-wise sales
- Product-wise profit
- Segment-wise sales
- Monthly sales trends
- Yearly sales performance
- Discount analysis
- Units sold analysis
